# WealthOS

> Your personal financial operating system.

WealthOS is a self-hosted web application designed to help long-term investors manage, analyze, and understand their complete financial life.

## Vision

WealthOS is more than a portfolio tracker.

It is a financial operating system that brings together:

- Investments
- Net Worth
- Goals
- Loans
- Cash Flow
- Analytics
- Investment Journal
- Historical Performance

into one unified platform.

## Guiding Principles

- Financial data is immutable.
- Every number must be explainable.
- One source of truth.
- Architecture before implementation.
- Quality over speed.
